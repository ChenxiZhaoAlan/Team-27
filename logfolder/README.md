# Change log folder

Create one file per meaningful release or push: `YYYY-MM-DD-short-description.md`.

Template:

## Change summary
- ...

## Files modified
- `path/to/file` — reason

## Checks performed
- `pnpm build` — PASS/FAIL/SKIPPED (state why)

## Git details
- Branch:
- Commit SHA:
- GitHub PR/push link:

## Follow-ups / risks
- ...

Note: this records release-level decisions; Git commits are the authoritative diff history.
