# Team 27 Proposed Roadmap

These items are proposals to review, not approved implementation requirements.

## Phase 0: audit and stabilize
- Inventory repository structure, framework, dependencies, routes, and build commands.
- Run existing build/test/lint; document current issues.
- Identify logo and navigation implementation, homepage red triangle, language setup.
- Review responsive behavior and accessibility.

## Phase 1: club website foundation
- Confirm design system and finalized identity (The 27 Society).
- Review club introduction, events, member profiles, sponsors, and social links.
- Choose bilingual content strategy and privacy-aware member display.

## Phase 2: maintainability and release workflow
- Make deployment process reproducible and documented.
- Implement commit/change log convention in `logfolder/`.
- Add checks for broken builds and basic regression tests.

## Phase 3: optional poker functionality (separate project decision)
- Explore AI training/play modes and member-versus-member gameplay.
- Evaluate authentication, matchmaking, real-time networking, anti-cheat, state persistence, moderation, user safety, and resource costs.
- Determine whether play is social/points-only; obtain legal review for applicable NZ gambling restrictions before any stakes/prize features.
