## 改了什么

- 源码从 dist 迁出，拆成 core、data、pages、features、motion、ui、styles；图片和字体使用真实独立文件。43 个 src 文件，最长源行 328 字符，业务源文件不含内嵌图片数据。
- dist 仅由构建生成；单文件 HTML 独立作为演示发行物。移除旧 Python 打包入口，以 pnpm build 统一构建。锁定构建依赖，补充 README。
- CSS 按职责整理，删除开屏旧定位/旧 padding 等覆盖残留。保留响应式的比例构图、菜单断点、矮屏开场布局。
- 首页标题不再放入裁剪容器，调整行高、字形空间，移动端使用真实词间空白。2 和 7 共用红色细边样式。
- 页面动效、开场、转场分别管理生命周期，页面卸载清理动画与监听。暂停动效不重建整个页面，保留翻牌和答题状态。
- 活动筛选只替换列表；下一手只替换练习区域并恢复焦点。修正 BFCache 场景下 pagehide 一次性监听问题。
- 离线构建检查插入标记、资源边界、缺失资源及 HTML/CSS 文件依赖；嵌入图片按短行 JSON 保存，字体去重。
